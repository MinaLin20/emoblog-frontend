EMO Login (React + Tailwind)

How to run

- Install deps: `npm i`
- Start dev server: `npm run dev`

Background image

- Put your background image at `public/bg.jpg` to match the design. A dark, night-sky mountain photo works best.

Responsiveness

- The layout targets desktop width 1440px and handles 360px–1440px gracefully. A custom `xs` breakpoint at 360px is configured in `tailwind.config.js`.
